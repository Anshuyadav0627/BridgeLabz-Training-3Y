Responsive CSS Cheat Sheet

Filters

CSS filters change the appearance of elements.

filter: grayscale(100%);

Media Queries

Media queries apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites work on different devices.

width: 100%;

Typography

Responsive text can adjust according to screen size.

font-size: clamp(1rem, 2vw, 2rem);
